Turn these 10 concepts in 2 minutes and you will understand the foundation of every modern LLM. The same foundation behind chargeability and 300 billion AI industry. Number 1. Tokenization. An LLM does not read full sentences like humans. It breaks it down into small units called tokens. Token's can be words, part of words, numbers, space and punctuation. So your prompt first becomes a sequence of tokens. Number 2. Embeddings. Each token is converted into vectors. A vector is just a list of numbers. Think of embeddings as coordinates in a meaning space. Similar meanings end up closer together in the vector space. Number 3. Positional encoding. The model also needs to know the order of tokens because dog bites man and man bites dog have same tokens effectively different meaning. So positional encoding adds positional information. Basically it tells this is token 1, this is token 2, this game before that. Modern models often use methods like rope or rotatory positional embeddings to handle this. Fourth. The transformer block. Now these vectors are entered into transformer. A transformer is a stack of repeated processing layers. Each layer refines the representation of the text. Number 5. The self-attention mechanism. Self-attention decides which token should influence each other. It helps the model connect instructions, context, grammar and relationships. Technically attention uses queries, keys and values. Query means what I am looking for. The key means what information exists and the value means what information should I use. Number 6. Feed forward network. After the attention the data goes through several neural networks inside the transformer block. This is where the model transforms the patterns, meanings and relationships into richer representations. Number 7. Logits. At the end the model produces raw score scored logits. Each logic is a score for a possible next token. For example, Palacemeix score higher, Londonmeix score lower and Banana Avery low score. Number 8. Softmax. Softmax converts logic into probabilities. Think of it as a score to percentage converter. It makes all possible next tokens probabilities adding up to 100%. So Palace might be 92% London 7% and Banana 1%. Number 9. Stampling. The model then selects the next token. Sometimes it picks the higher probability token. Sometimes it samples from the probability distribution using setting stack temperature or top P. That's why same prompt can produce slightly different answers in the locations. Number 10. Training versus inference. Training is when modelers. It predicts tokens, calculates error using a loss function and updates its weights using a back propagation or a gradient descent. Inference, on other hand, is when you use a trained model. The weights are frozen. Your prompt becomes a temporary context. The model generates the output one token at a time based on your prompt. So the full pipeline is Texas converted to tokens and embeddings. And then they are positionally encoded, which goes through a transformer block, where self-attention mechanism finds the important weights converted to logics, goes through a soft MAC function and sampling happens to generate the next token. That loop repeats again and again until the answer is complete. An LLM isn't magic. It's a transformer repeatedly predicting the next token billions of times over massive amounts of data.
